# خادم القاهرة التاريخية (Backend)

خادم Node.js/Express بسيط يستقبل الحجوزات وطلبات المتجر ويجهّز عملية الدفع.

## التشغيل محليًا
```bash
cd backend
npm install
cp .env.example .env
npm start
```
سيعمل الخادم على `http://localhost:4000`.

## نشره مجانًا (اختر واحدة)
1. **Render.com** — أنشئ حساب مجاني → New Web Service → اربط مجلد `backend` (عبر GitHub) →
   Build Command: `npm install` — Start Command: `npm start` → احصل على رابط دائم مجاني.
2. **Railway.app** — نفس الفكرة، بخطة مجانية محدودة الساعات شهريًا.
3. **Cyclic.sh** أو **Fly.io** — بدائل مجانية أخرى مناسبة لتطبيقات Node الصغيرة.

بعد النشر، خذ الرابط الناتج (مثل `https://historic-cairo-api.onrender.com`)
وضعه في متغيّر `API_BASE` أعلى ملف `frontend/index.html`.

## تفعيل الدفع الحقيقي
1. سجّل حساب تاجر لدى بوابة دفع مرخّصة في مصر تجمع كل الوسائل (الأسهل: **Paymob**،
   أو **Fawry Business**).
2. ضع القيم في `.env`:
   ```
   PAYMENT_PROVIDER=paymob
   PAYMENT_API_KEY=المفتاح_الذي_تحصل_عليه
   ```
3. فعّل الكود المعلَّق داخل دالة `initiatePayment()` في `server.js` واستبدله
   بطلب HTTP الحقيقي حسب توثيق البوابة التي اخترتها.

قبل الحصول على مفاتيح حقيقية، يعمل الخادم تلقائيًا في **وضع تجريبي (Demo Mode)**:
يحفظ الحجز/الطلب ويولّد رقم مرجعي وهمي، دون أي دفع حقيقي.

## تفعيل "صديق الرحلة" (المرشد الذكي) بعد النشر
داخل معاينة الموقع على Claude.ai، يعمل المرشد الذكي تلقائيًا دون أي إعداد.
لكن بعد نشر الموقع على استضافة خارجية (Netlify/Render...)، يحتاج الأمر
مفتاح Anthropic API حقيقي على الخادم فقط (لا يوضع أبدًا في كود الواجهة الأمامية):
1. أنشئ مفتاحًا من **console.anthropic.com**.
2. ضعه في `.env`:
   ```
   ANTHROPIC_API_KEY=مفتاحك_هنا
   ```
3. أعد تشغيل الخادم — سيبدأ `POST /api/guide/chat` بالرد الفعلي فورًا.

بدون هذا المفتاح، سيستمر الشات في العمل لكن برسالة توضيحية بدل إجابات حقيقية.
ملاحظة: هذه الميزة تُستخدم بالفوترة القياسية لواجهة Anthropic API حسب عدد
الرسائل، فراجع أسعار النماذج على docs.claude.com قبل الإطلاق للجمهور.
